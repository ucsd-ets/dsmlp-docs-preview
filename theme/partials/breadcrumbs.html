{# CANVAS. Breadcrumbs sit inside main#main-content in the shipped two-column template, so they are the site's to generate. page.ancestors runs immediate-parent-first, so it is reversed here. MkDocs Section objects carry no url of their own; a section links to its first page (partials/nav-macros.html) rather than rendering as dead text. A section's landing page stands for the section (navm.landing), so on that page the trail ends at it rather than naming the section and then the page: HOME / Access, not HOME / Access / Access. The home page has no trail: it would only say HOME twice. And no crumb links to the page the trail ends on: a section with no landing page links to its first page, so on that page its crumb is text. #} {%- import "partials/nav-macros.html" as navm %} {%- if page.url %} {%- set trail = page.ancestors|list %} {%- set trail = trail[1:] if (trail and navm.landing(trail[0]) and trail[0].children[0] == page) else trail %}
  1. HOME
    2. {%- for anc in trail|reverse %} {%- if anc.is_page and anc.url %}
  2. {{ anc.title }}
    3. {%- elif anc.children and navm.first_url(anc) and (navm.first_url(anc)|string) != page.url %}
  3. {{ anc.title }}
    4. {%- else %}
  4. {{ anc.title }}
    5. {%- endif %} {%- endfor %}
  5. {{ page.title }}
{%- endif %}
