# Images

------------------------------------------------------------------------

Inline images for the documentation set, referenced with relative paths:

```markdown
![The Datahub environment menu](images/datahub-spawn-menu.png)
```

From a shared technical page one directory down, that becomes
`../images/datahub-spawn-menu.png`.

## Conventions

- **PNG for screenshots**, SVG for diagrams that are drawn rather than captured.
- **Name by what it shows**, not by where it appears:
  `datahub-spawn-menu.png`, not `student-page-fig-1.png`.
- **Every image needs real alt text.** Describe what the reader is meant to see,
  not the fact that it is a screenshot.
- **Capture at a sane width**, and not as a retina-scaled 4000px file.
- **Re-shoot rather than annotate over stale UI.**
